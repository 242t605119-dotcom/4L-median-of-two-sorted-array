# LeetCode 4 - Median of Two Sorted Arrays

## Problem
Find the median of two sorted arrays.

## Example
Input: [1,3], [2]

Output: 2.0

## Approach
Combine the two sorted arrays and find the median value.

## Complexity
- Time: O(n + m)
- Space: O(n + m)

## Language
Python

Hard
